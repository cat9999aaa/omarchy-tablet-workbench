# v0.2.1 右手触屏优化

用户2026-10-17明确批准：候选贴近键区，模式、语音、收起集中下方；删去固定问候短语，增加复制粘贴，仅保留一套桌面触屏输入法。

1. 备份现有源码/部署清单；新增真实Qt布局距离、单入口、Fcitx快捷键回归并观察失败。
2. 将候选与拼音组合贴至键区，保留上方语音预览/词库设置。字母组大标签，右上大退格不变。
3. Fcitx桥仅允许固定编辑快捷键；组合中禁用，敏感字段禁复制剪切全选，保留粘贴。
4. 取消P1旧wvkbd自动回退，旧入口和原型归档，锁屏与LUKS键盘独立保留。
5. 全套CTest、独立GTK真实输入、版本化部署/IPC核验，受控更新启明及GitHub。

设计参考Android官方触控目标建议；本机Qt逻辑像素不等于Android dp，不能声称已满足物理尺寸规范。实际手感仍需用户使用反馈。

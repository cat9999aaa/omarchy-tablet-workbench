# DASHEN Overdrive

原创深色 Omarchy 主题，属于 DASHEN // OVERDRIVE（大神 · 超频计划）。
深色底板、暖橙操作强调与清晰状态配色；无循环动画和虚构仪表。

本包只有 colors.toml、shell.toml、README.md、LICENSE、source.json。
不包含背景图片、字体包、脚本或运行时网络依赖；中文使用系统字体回退。
主题不是完整桌面或 MAGI 实现，不改变设备状态、输入入口或服务。

安装前将目录复制到用户的 Omarchy themes 目录，通过官方主题入口选择
DASHEN Overdrive。请先记录原主题名；恢复使用官方入口重新选择原主题。
本阶段真实切换、无背景时的行为及应用存续尚待隔离与实机验收，
不要将静态校验通过等同于已部署。保留用户 shell.toml 覆盖，不删除配置。

开发检查：`python3 scripts/themes/check_theme.py themes/dashen-overdrive`。
配色对比度检查不等于最终混合渲染或无障碍认证。
参考 EVA 的信息表达语言，没有复制标志、截图、字体或第三方组件。
原创内容 GPL-3.0-only；官方主题键作为兼容接口使用。

# 插件版本发布与恢复验收

范围：已有输入法、网络、电池、控制台用户插件的 QML/JS/assets 更新。正式业务功能和设备验收独立记录。

实现了包清单校验、官方插件校验、监视目录外完整准备、版本目录与 manifest 原子切换、旧版保留、固定只读版本探针、异常恢复、每插件锁和事务记录。初始探针、准备、发布探针与恢复探针期间的并发修改均拒绝误报或覆盖。

独立审查发现两项重要问题：初始等待后的重新取样可能掩盖并发修改；新版本探针成功后缺少最终文件复核。均已修复并增加回归；恢复路径同样追加最终 hash 核对。无延后处理的重要项。

本机对运行中的输入法0.2.3复制当前5个QML文件，打包并执行只读plan；识别版本相同、不需要更新。前后 manifest 字节、运行版本、后端PID未变。没有为了测试制造新版本，也没有调用真实apply/rollback。

授权Arch远程隔离环境20/20项测试通过（plugin-release-03最终运行）；证据与 GitHub 门禁在任务记录维护。第一次扩展测试17项中16项通过，1项因隔离环境无HOME而失败；测试fixture改为显式临时HOME。随后远程隔离命令缺少lib64加载器映射，失败记录保留；不能算源码测试结果。

正式范围边界：隔离模拟命令验证事务逻辑，不证明真实Omarchy热加载/异常恢复。首次实际使用还需在下一次有业务变化的新版本中验收。未升级系统服务、代理核心、启动链路或个人数据库。文件锁只协调本工具，不能阻止外部编辑器在最终检查后的写入。

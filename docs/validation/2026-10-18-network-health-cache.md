# 网络健康缓存边界修复

原status直接对缓存根对象调用get并做时间减法。非对象JSON及空/字符串时间导致异常；NaN、Infinity和过远未来时间可保留为健康缓存。

抽取read_health_cache：只接受当前物理接口、对象结构、有限数值时间及-5到65秒闭区间的观察；非法缓存降级为空，由现有UI显示未确认。保留合法缓存及既有接口切换淘汰，不增加探测或网络控制动作。

远程隔离回归：新用例在原实现复现4个失败、8个异常子例；修复后完整网络60项通过。覆盖实际status消费者、错误类型、非有限/巨大数、未来及过期边界和接口改变。全仓库软件验收与GPS构建由当前提交GitHub CI确认。

这是候选源码验证，不代表本机部署、代理接管或真实断网恢复。部署需保留本机已有代理转交与服务名差异，禁止直接覆盖整份network.py。

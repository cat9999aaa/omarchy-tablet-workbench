# 控制台动作准备重构

## 原因与边界

原 prepare 在每个非滑块操作中构造整张命令表，并立即读取两次电源上下文。打开网络页、锁屏、阅读器等无关操作也承担电源读取；balanced 可能采用第二次读数。

按现有控制台设计做内部重构：先检查锁屏与参数，随后只生成选中动作的命令，资源锁归属独立表达。静态命令使用不可变参数元组，每次请求生成独立列表。电源操作只读一次上下文，音频操作才解析输出设备。保持公开 prepare 返回结构、命令白名单、二次确认、资源锁及特权请求身份；execute 和 root 授权检查不变。

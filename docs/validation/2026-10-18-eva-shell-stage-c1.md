## 失败及修正

1. 双屏归属测试在拔屏后重试超时。增加自动保存延迟稳定复现：测试使用全局 choice，第二屏的 tablet 设置泄漏到第一屏。产品 device_session 已按 output_key 存储。修正模拟设置按屏幕隔离，新增明确断言；保留延迟以覆盖取消保存，定向及完整候选通过。未改产品路由逻辑。
2. GitHub Qt 6.4.2 的网络/电池测试在对 QML children 使用 for-of 时 Type error；远程 Qt 6.11.2 原先通过。改为索引遍历，远程 6 项及 GitHub 完整检查通过，不降低测试门槛。
3. 打包元数据采集初次错误地从远程宿主 PATH 查询 rustc；构建器实际位于隔离覆盖层。未生成发布包；改为读取本次 Cargo 缓存记录的成功 rustc 信息，记录原构建器及 ABI，不在平板编译。

4. 独立审查指出 null-token 的 TouchButton 强制应用字体，破坏父控件继承。先复现父字体 29 实得 12；修复为无 token 时复位原生 font，覆盖父字体变化、启用/撤销 token、按下期间字体热更新及显式字号。`22aaa65` 同步副本后统一 33 组通过。
5. 独立审查发现网络测试只加载 TravelControls，遗漏 Panel 的 Wi-Fi 默认内容。新增从产品源提取的真实 Wi-Fi 表单，边界仅替换 I/O；复现开关 44×28 和禁用确认图标对比度不足。触摸区域统一至少 48，确认按钮采用共享可读禁用态；验证输入对象/文本在热更新中保留。
6. 非空历史曲线补测复现 100% 与功率上限重叠。采用 Canvas 实测文字宽度计算边距和时间标签分行，补字体族变化重绘；实际绘制标签无重叠/越界，两段曲线保留缺口。定向 202 及最终 976 图通过。

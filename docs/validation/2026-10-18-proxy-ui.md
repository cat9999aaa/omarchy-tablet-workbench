# 代理界面原型验证

日期：2026-10-18。仅本地 HTML 设计原型；所有状态与节点均为虚构，未操作生产网络。

| 检查 | 结果 |
| --- | --- |
| 代理关闭确认；收起后再打开 | 模拟状态保留 |
| 快捷控制与完整界面 | 同一状态；从快捷面板重新开启成功 |
| 搜索“东京”并切换示例 B | 成为当前节点 |
| 选择全局但尚未应用 | 顶部仍显示规则分流 |
| 离开未应用草稿 | 出现放弃确认；取消后可继续应用 |
| 应用分流 | 模拟校验完成后顶部显示全局 |
| 节点失败情景，尝试切到 B | A 仍为当前节点 |
| 授权取消情景 | 运行模式保持规则分流，草稿未应用 |
| 断网与模拟恢复 | 状态栏和物理出口分别显示未连接/恢复 |
| 首次使用导入预览 | 确认后加入示例；代理仍关闭，没有擅自开启 |
| 更新成功 | 当前组合 B 与结果一致 |
| 更新失败/查看恢复结果 | 明确显示恢复组合 A；只验证演示状态 |
| 800×1280 竖屏 | 无水平溢出；可见按钮高度均至少48 CSS像素；页脚在视口内 |
| 390×844 窄屏 | 页面选择可切至分流；修正后页脚 bottom=828，视口内；无水平溢出 |
| 1280×800 横屏 | 截图检查；固定外框、状态栏和页脚可见 |
| 浏览器捕获的 error/warn | 检查时为空 |

# 夜间模式与窗口直达验收

控制台 0.1.7 与导航 0.1.1 已部署。本次夜间模式指屏幕暖色护眼，不改变主题或应用配色。

- 快捷九宫格、设备详情、飞行娱乐页共用 Omarchy 官方夜间开关。原禁用的显示方向占位替换为夜间模式，固定面板仍为 640×604。
- 实机通过受控入口开启，官方读回 4000 K；关闭读回 6500 K，控制台两次均显示对应状态。温度未知不会显示成关闭。
- 38 项远程 Python 检查与 JS 状态/布局检查通过；独立代码审查未发现重要问题。隔离测试环境最初缺相邻模块、私有 /proc 和 Node 路径，修正测试启动环境后分别通过，未修改安全断言。
- 旋转键默认窗口操作，下方桌面 1–9；已有用户自定义不覆盖。640×604/480×540 下九个按钮无需滚动，触摸目标与合成点击通过；远程11项Python与8组QML布局行为通过。生产同实体键的软件入口已读回窗口页。
- 两项部署保留旧版本及 manifest 备份，不修改系统 Omarchy 源码，也不重启网络。夜间测试后恢复原色关闭。

新按钮真实手指、旋转实体键、竖屏硬件与冷启动未验。截图命令本次超时，没有把运行状态读回写成截图验收。

连续语音“停止即追加”的需求已确认，但本轮仍在处理原生录音生命周期与安全提交边界，未部署语音改动；输入法保持已验UI0.2.5/后端0.2.4。

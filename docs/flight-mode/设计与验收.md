# 飞行娱乐模式（2026-10-17）

来源：用户明确要求“真·飞行模式、只提供娱乐功能、开始干”。扩展现有网络控制器和三指控制台，不另造桌面、不关闭用户文档、不更改内核。

进入：保存原有 NetworkManager 总开关、Wi-Fi/WWAN、rfkill 开关与 ModemManager 电源状态；关闭全部 rfkill 设备、NM 网络与无线，显式禁用 ModemManager 模块并请求 low 电源。只有实际读取无线、模块电源与禁用状态均满足条件，才显示“无线关闭已确认”。模块消失、未知、缓存过期都不能当成功。失败保留已关闭部分和恢复记录；允许重试关闭或退出恢复。授权后和每个写操作前继续检查锁屏。

界面：飞行请求存在时，原三指控制台固定外框内切为离线娱乐。仅呈现游戏、视频、音乐、阅读，以及输入法、亮度、音量、电池、锁屏和退出。现有任务、文件、保存内容保留。不是应用权限沙箱，也不强杀其他程序。

后台：本项目代理自动拉起/用户退出跟踪和外网健康探测暂停，保留单实例代理、分流、ZeroTier配置与服务；不重新配置路由。GPS为接收设备，不是蜂窝发射开关，不因飞行模式承诺所有未识别外设关闭。

恢复：恢复进入前开关，原来关闭的无线继续关闭。模块编号变化或设备缺失保留恢复记录并报错；不会自动删除证据假报成功。联网开关恢复不等于公网已通，由现有网络健康检测继续确认。

蓝牙手柄/耳机在严格飞行模式中不可用，使用触屏、USB手柄或有线耳机。所有机上使用服从乘务要求。本版不保证未实测的开机早期射频时序、外挂未知无线设备、手动从其他应用重新开启无线后的强制隔离。

实施与验证：先新增故障回归（射频仍on、状态未知、取消权限、恢复原状态、禁探测），再修改控制器；远程执行现有network/control/JS测试，本机做只读状态及Qt界面验收。部署备份root工具与用户插件、版本化reload。当前在线会话不自动执行真实断网测试；实机关闭/恢复和冷启动留明确待验。

依据：[NetworkManager RFKill](https://networkmanager.dev/docs/rfkill/)、[nmcli](https://networkmanager.pages.freedesktop.org/NetworkManager/NetworkManager/nmcli.html)、[ModemManager官方D-Bus定义](https://github.com/linux-mobile-broadband/ModemManager/blob/main/introspection/org.freedesktop.ModemManager1.Modem.xml)。

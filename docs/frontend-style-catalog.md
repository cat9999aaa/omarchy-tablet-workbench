## 维护与交付规则

1. 每次前端修改前，检查表中是否已有合适组件；新增复用组件必须登记职责、调用方和验证项。
2. 每次前端提交更新受影响行及下方交付记录；软件通过、已安装、用户反馈分别填写，不用笼统“完成”。
3. 页面提供数据和语义，不复制组件样式；确需例外，表中写出原因和范围。共享层中的集中默认值允许存在，不要求消灭所有数字。
4. 四份Workbench发行副本只由scripts/workbench-ui/sync.py生成，--check防漂移；不能单独改某份。同步源码不等于发布四个插件，生产更新仍按各自版本与恢复流程。
5. 新组件无设备I/O、无进程、无命令执行；权限、采集和窗口动作归业务适配。禁止把不同用途硬塞进万能schema。
6. 验收覆盖320/480/640逻辑宽、1/1.25/1.5字体、中文、选中/禁用/焦点及主题热更新。实体触摸、笔、真实输出归属另外验收。

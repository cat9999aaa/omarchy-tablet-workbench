# C1 安装与恢复流程

本流程用于已安装且已启用的四个工作台插件。只读软件候选通过后，仍需独立审查和下面的本机准备。包摘要用于完整性核对，不是数字签名。每个插件独立事务，官方主题最后应用；不提供自动整批发布或断电恢复服务。

## 准备

1. 确认本次候选、插件 ID/版本/角色、运行版本与锁屏状态。必须通过 `omarchy-shell lock isLocked` 得到精确 `false`；`loginctl LockedHint=no` 不能单独证明 Omarchy 已解锁。未知、超时或返回 true 都停止实际安装，且每次真实切换前重新检查。控制台 0.2.1 需要已验 B2 Python 模块、固定离线契约库和包内 `bin/pcadmin-device-observer`，不得只替换 QML。核对 observer 的源摘要、编译器、动态依赖、目标 ABI、0755 模式及二进制摘要。
2. 逐文件备份本批将修改的兼容 helper、共享源、UI、manifest、原主题名、当前主题与背景链接状态；官方后置命令的配色文件也记录存在/缺失（包括 root 浏览器 color.json），提前确认能够恢复缺失状态；另记录GNOME的color-scheme、gtk-theme、icon-theme三个值，重新应用原主题可能把用户原有图标偏好重置成主题默认；私人运行数据不进入公开包。将备份还原到临时目录并核对摘要。保留版本和事务记录，不删除原插件文件。
3. 用 `modules/plugin-release/release.py plan` 对每个包执行只读检查。真实插件 ID 以安装 manifest 为准；导航只能是 `pcadmin.navigation`。不要把示例账户前缀复制到其他用户的设备。
4. 阅读当前官方 `omarchy-theme-set` 及完整后置命令；只记录用户 hook 的脱敏元信息，不公布私人正文。需要确认模板生成、应用配置更新、浏览器策略、硬件灯效和缓存动作的范围与恢复路径。遇到无法保证应用/输入会话保留的动作，保留软件候选并说明具体未解决项；不要用测试 headless 开关跳过生产链。
5. 通过官方扩展目录放置已校验的五文件主题。已有同名用户主题必须先比较来源与摘要，不无条件覆盖。保持用户 shell.toml、shell.json、背景和字体偏好。若当前背景链接位于将被官方切换替换的 current/theme 内，先把原图保全到本机持久备份并验证摘要，再准备官方支持的用户背景路径；确认切换后的链接仍有效。背景不加入公开五文件主题包。

## 执行

- 先安装已核对的兼容 helper/依赖，保留原转交适配与恢复副本；不修改原服务、timer、触摸模式、代理或输入法归属。
- 按控制台、导航、网络、电池逐个调用既有 `apply`。每次保存返回事务 ID，核对运行版本、manifest 及有效负载摘要。发布器自身检查Omarchy锁屏，并对控制台额外验证ready；原始版本探针不能替代实际打开验收。一个失败就停止后续发布。
- 所有插件通过后，最后调用官方主题设置入口。核对实际主题名、色板和运行界面；记录本批确实改变的文件及其前后摘要。主题命令退出成功不能代替界面读回。
- 锁屏或不能验证时停止实际切换，交付候选与备份恢复材料并明确“未安装”；不能把软件测试写成实机完成。

## 失败恢复

先处理最后改变的主题，再按电池、网络、导航、控制台的反序恢复本批成功应用的插件；未执行的项目不触碰。失败中的单插件事务先检查其 journal，区分已自动恢复、未验证与冲突。

主题恢复必须先确认当前主题和待恢复文件仍属于本次写入，再走原官方主题名。背景、用户覆盖或其他文件仅在当前摘要/链接目标仍等于本批写入结果时恢复；若用户已改动，则保留并报告冲突。不要整份覆盖用户配置。官方主题重新应用可能重新选择背景，必须另核对并恢复本批所改变、仍可确认归属的背景链接。

插件调用原事务的 `rollback`，由发布器验证当前 manifest 和备份摘要、读回原运行版本。任何 `conflict-preserved` 或 `rollback-unverified` 都不是恢复成功；保留证据并继续核对其他独立事务。控制台先恢复 UI 再恢复 helper，避免新 UI 配旧 helper。

`test_batch_recovery.py` 演练该顺序中的第三插件失败、主题步骤失败及并发编辑。主题只使用合成标记，不执行真实官方后置钩子，因此仍需本机备份与恢复核验。

## 验收记录

分别记录软件检查、发布包、已安装运行版本、视觉反馈、实体交互和性能。开页/切页 P50/P95、CPU/PSS、冷启动、睡眠、真实触屏/笔及应用存续未测就保持未验证。C1 不等于 C2/C3 或整个 DASHEN 生态完成。

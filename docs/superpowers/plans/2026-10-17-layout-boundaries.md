# 输入法与导航布局边界验收

归w-0031，沿用已批准的右侧输入区、右上退格、固定外框内部滚动和触屏优先方案。新增测试不触发真实设备操作。

1. 补足实际横屏440×829及竖屏440×1501的6模式×4状态布局矩阵，保留既有功能检查。数字/英文不伪造拼音候选，手写候选独立覆盖。
2. 以六个候选复现全拼高度超限；合并非九键退格与候选区，保留字号、数字行与退格尺寸，不靠整体缩小解决。
3. 导航实际按钮逐个检查触控尺寸、文字边界、横向范围、滚动可达与模拟点击调用，测试不执行系统动作。
4. 远程隔离验收；本机只渲染兼容预览，版本化部署与恢复。物理旋转、手指舒适度仍独立待验。
5. 同步便携源码与GitHub自动检查，启明更新已有会员和任务，不新建重复会员。

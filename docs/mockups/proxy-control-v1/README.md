# 原生代理管理 · 交互原型 01

这是 Omarchy Tablet Workbench 的设计预览，并非 Omarchy 官方产品，也不是可用的代理客户端。所有节点、延迟、检测和更新结果都是模拟数据。

直接用浏览器打开 `index.html` 即可。也可仅在此目录启动本地静态预览：

```sh
python -m http.server 8766 --bind 127.0.0.1 --directory docs/mockups/proxy-control-v1
```

访问 `http://127.0.0.1:8766`。无需安装前端依赖、构建或访问 CDN；服务用完可停止。

## 怎么体验

1. 总览 → 切换节点 → 搜索“东京” → 使用此节点。
2. 分流 → 全局代理。顶部仍显示原模式，点击“应用修改”才更新；离开未应用的修改会提示。
3. 顶部“快捷控制”与完整页面共用模拟状态；“收起”后重新打开，状态保留。
4. 顶部“演示情景”可选择断网、节点切换失败、更新失败、首次使用、等待授权。
5. “重置演示”或刷新恢复初始状态。

本页不读取设备状态、不接收真实订阅、不连接网络控制服务、不请求授权、不修改系统。操作仅保存在当前页面内存；页面关闭后不保留。正式实现采用 Qt/QML 与统一控制服务，此 HTML 只用于评审交互，不是最终运行架构。

横屏和竖屏截图分别为 `landscape.jpg`、`portrait.jpg`。正式交互要求和验证边界见仓库中的 `docs/superpowers/specs/2026-10-18-proxy-ui-design.md`。
